Multi-Doppler Radar Airspace Abnormal Monitoring System: Isolation Forest-Based Approach for Aircraft Threat Identification
Introduction: Low and full airspace monitoring are core needs in the fields of security and air traffic management. Traditional radar monitoring relies on manual target trajectory identification, which faces challenges such as latency, high missed rates, and unquantifiable risk when dealing with massive real-time echo data. To address this industry issue, this paper shares an intelligent radar abnormal detection system that integrates physical radar simulation, temporal feature mining, and multidimensional threat quantification. It leverages unsupervised machine learning algorithms to automatically identify anomalous maneuver behaviors of non-cooperative targets, simultaneously outputing interpretable threat levels suitable for various scenarios including air traffic control duty, border airspace security, and low-altitude control in key areas.
1. System Development Background and Application Value (I) Industry Pivotal Challenges:
1. Manual Detection Efficiency Issues: The radar continuously outputs five types of monitoring data: distance, bearing, echo power, Doppler shift, and relative velocity. Within the airspace, aircraft generate a continuous stream of time series data, resulting in tens of thousands of monitoring records per station daily. Operators spend long periods visually screening trajectories, which is prone to fatigue and struggles to quickly capture short-term, covert anomalous maneuvers.
2. Standard/Abnormal Behavior No Standardization: Regular civil and commercial aircraft typically exhibit four standard flight patterns: straight cruising, gentle turning, steady climbing, and steady descending. Suspected targets often display rapid turns, serrated maneuvers, speeding up or down, ground looping, or dramatic altitude changes—non-standard actions. Traditional systems can only show trajectories but cannot automatically distinguish between these two categories of behaviors.
3. Risk Assessment Lacking Quantitative Standards: Current monitoring can only label "abnormal/normal" as a binary result, unable to differentiate minor deviations from high-risk close-in actions, lacking a tiered warning mechanism, making operators struggle to intuitively judge priority for event handling; furthermore, there is no traceability for anomaly alerts, preventing explanation of the core cause of the target's anomaly.
4.
The simulation and actual data are disconnected. Most monitoring systems lack standardized simulation platforms, relying on real aerial acquisition data for model training. The scarcity of real abnormal samples weakens the model's generalization ability. Offline testing and online real-time monitoring logic are not unified, making it difficult to ensure model accuracy.

✅ Establish a normalized real-time duty system for airspace, constructing a visual operation terminal to render the full radar coverage area, multi-station radar coordinates, and the dynamic trajectory of aircraft. It automatically monitors target flight status continuously, outputs quantitative threat scores in real time, and triggers voice alarms for high-risk behaviors.

II. System Architecture and Operational Logic
(I) Flight Motion Simulation Layer
(II) The multi-site Doppler radar simulation layer completes signal simulation based on the true radar physical principles, rejecting traditional simplified estimation formulas and adopting a four-fold inverse radar echo power model coupled with Doppler frequency shift calculation logic to restore the real ground radar detection mechanism. The system establishes a four-site ground radar network, allowing any site to serve as the primary monitoring base station. A single detection outputs five standardized monitoring indicators with Gaussian noise: target distance, horizontal azimuth angle, echo signal power, carrier Doppler frequency, and relative radial velocity of the target. Changes in motion state will synchronize the simultaneous change in multiple types of sensor data: for example, when an aircraft accelerates at high speed, there will be regular offsets in relative velocity, Doppler frequency, and echo distance. This multidimensional data synchronization characteristic is the core basis for algorithm recognition of anomalies.
(III) The sequential data caching storage layer employs a sliding window caching mechanism to continuously store raw radar monitoring data. It sets a fixed window sampling length and a sliding step, entering the feature calculation process only after the cache is fully filled. Additionally, it supports the persistent storage of complete track data in local CSV files, balancing real-time inference with offline data retention needs.
(IV) The Temporal Feature Standardization Extraction Layer serves as the core standardization module of the system, unifying the full process of feature calculation rules. It extracts five types of statistical features for each category of radar monitoring indicators within a window: temporal mean, standard deviation, variance, maximum jump amplitude of adjacent sampling, and linear trend slope of temporal change. A total of 25-dimensional standardized feature vectors are generated from five radar channels. The model training, real-time monitoring, and offline judgment all reuse the same set of feature calculation rules, eliminating the issue of recognition failure due to inconsistent features under different scenarios at their root.
(5) Unsupervised Intelligent Identification Module: The isolated forest is selected as the core anomaly recognition algorithm. This algorithm is suitable for unsupervised identification scenarios: only full normal aircraft trajectory features are used for model training, without the need to collect a large number of high-risk anomaly samples, perfectly adapting to the industry reality where real airspace anomaly samples are scarce. The model outputs raw anomaly scores, with lower scores indicating that the target behavior deviates from the normal airspace patterns more severely; it also completes binary classification markings, distinguishing between normal windows and suspected anomaly windows.
(VI) Multi-dimensional Threat Quantification Engine distinguishes itself from traditional binary judgment models by constructing a three-tiered weighted integration threat scoring mechanism. It transforms identification results into a quantifiable threat score ranging from 0 to 100, with the weights allocated as follows: Machine learning identification results account for 50% of the weight, radar signal anomalies feature accounts for 25%, and aircraft maneuvering behavior features account for 25%.

Machine Learning Dimension: Based on the score distribution of training dataset, a percent-based mapping is made to quantify the degree of anomaly determined by the model.
2  
Radar Signal Dimension: For the calculation of characteristic deviation from baseline, Z-score is used to quantify the degree of signal distortion based on backscatter power and Doppler frequency.
3  
Flight Behavioral Dimension: Calculate baseline deviation in terms of distance, orientation, and radial velocity temporal features to quantify the degree of aberrant maneuvers.
